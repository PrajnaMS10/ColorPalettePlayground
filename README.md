# 🎨 Color Palette Playground

## 📌 Project Description
Color Palette Playground is a simple web-based application built using HTML, CSS, and JavaScript.  
It allows users to generate random and harmonious color palettes, copy individual color codes, lock favorite colors, switch between light and dark themes, and export the entire palette for reuse.

This project demonstrates DOM manipulation, event handling, color generation logic, and effective use of AI-assisted development using Cursor.

---

## 🎯 Features

- 🎨 Generate random color palettes with 5 color swatches
- 🌈 Harmonized palettes using HSL (similar colors like blues, greens, etc.)
- 🔒 Lock individual colors to prevent changes during randomization
- 📋 Click any color to copy its hex code to the clipboard
- ✅ Visual “Copied!” feedback on successful copy
- 🌗 Light / Dark mode toggle (pure white & pure black backgrounds)
- 📤 Export palette feature to copy all hex codes at once
- 💻 Clean, modern, and responsive UI using Flexbox

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla)
- Clipboard API
- HSL Color Model

---

## 🚀 How to Run the Project

1. Download or clone the project folder.
2. Open the `index.html` file in any modern web browser.
3. Click **Randomize Palette** to generate colors.
4. Click a color swatch to copy its hex code.
5. Lock colors, toggle theme, or export palette as needed.
